# Security Policy

## Supported Versions

| Version | Supported |
|---------|-----------|
| 0.2.x   | yes |
| 0.1.x   | no (superseded) |
| < 0.1   | no |

## Reporting a Vulnerability

Please email louis-felix.nothias@cnrs.fr with the subject line
"SECURITY: indicium-adapters-metabolomics" rather than opening a public issue.
You can expect an acknowledgement within 7 days.
