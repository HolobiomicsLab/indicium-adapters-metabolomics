# Licences of the bundled data

The code of this package is under the MIT licence in `LICENSE`. The data files
under `src/indicium_adapters_metabolomics/data/` are derived from upstream
sources that keep their own licences. This file lists each bundled data file,
its source, the version used and the licence with the attribution it requires.
A copy of this file ships in the wheel as
`indicium_adapters_metabolomics/data/DATA_LICENSES.md`.

The files are regenerated by the maintainer scripts `build_data.py`,
`build_vocabs.py` and `build_synonyms.py` in the same directory. Those scripts
do not record the upstream release they read, so the versions below are the
dates on which the files were last committed to this repository.

## refmet_compounds.tsv

About 156,700 compound rows built by `build_data.py`.

- Names, InChIKeys and the ChEBI, HMDB, KEGG, LIPID MAPS, PubChem and Wikidata
  identifiers come from the Wikidata Query Service
  (https://query.wikidata.org/). Wikidata structured data is available under
  CC0 1.0 (https://creativecommons.org/publicdomain/zero/1.0/).
- The `refmet_name`, `chemical_class`, `super_class` and `pathway` columns of
  about 3,200 rows come from the RefMet REST service of the Metabolomics
  Workbench (https://www.metabolomicsworkbench.org/databases/refmet/).
  These values are used under the Metabolomics Workbench terms of use. The
  licence of RefMet has not been verified for this release; check the
  Metabolomics Workbench terms before redistributing the table on its own.

## _po_terms.json

1,363 Plant Ontology labels mapped to `PO:` identifiers by `build_vocabs.py`.

- Source: Plant Ontology, Planteome project
  (https://github.com/Planteome/plant-ontology), read from the OBO PURL
  http://purl.obolibrary.org/obo/po.owl, which resolves to the `master`
  branch of that repository. The tagged PO release current on the build date
  was v2026-01-09; the exact upstream commit was not recorded.
- Licence: Creative Commons Attribution 4.0 International (CC BY 4.0,
  https://creativecommons.org/licenses/by/4.0/).
- Attribution: Plant Ontology, Planteome project, CC BY 4.0.
- Changes: subset of plant-structure terms, labels lower-cased, each label
  mapped to its `PO:` CURIE. No definitions or axioms are bundled.

## _ro_terms.json

13 biotic-interaction relations of the Relation Ontology mapped to `RO:`
identifiers by `build_vocabs.py`, read from
http://purl.obolibrary.org/obo/ro.owl. The Relation Ontology is released
under CC0 1.0.

## _wd_organisms.json

460 organism labels mapped to Wikidata QIDs by `build_vocabs.py` through
the Wikidata Query Service. Wikidata structured data is available under
CC0 1.0.

## _uberon_terms.json

57 anatomical and biofluid terms, with synonyms written by hand, selected for
the optional matrix-name normaliser, each pointing at an UBERON identifier
(https://obofoundry.org/ontology/uberon.html). The list is a short manual seed,
not an extract of the ontology. UBERON is released under CC BY 3.0
(https://creativecommons.org/licenses/by/3.0/); it is credited here as a
courtesy.

## _synonyms_tier2.json

89 compound-name synonyms harvested by `build_synonyms.py` from PubChem
PUG-REST (https://pubchem.ncbi.nlm.nih.gov/), each pointing at a canonical
name already present in `refmet_compounds.tsv`. PubChem content is provided
by the National Center for Biotechnology Information under its data usage
policies; the terms that apply to these names have not been verified for this
release.
